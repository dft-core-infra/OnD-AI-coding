# 1. Initial Issue - LM Studio Model Download

The QuickStart guide contained outdated commands.

### Command attempted

```powershell
lms get qwen/qwen-3.6-35b-instruct-gguf --quant q4_k_m
```

### Error

```text
error: unknown option '--quant'
```

### Resolution

The current LM Studio CLI no longer supports the `--quant` parameter in that format.

Instead:

```powershell
lms search qwen
```

then

```powershell
lms get <model-name>
```

and select the quantization during download if prompted.

Reference came from the TeamOne On-Device AI Coding QuickStart discussion.

# Lessons Learned

1. The QuickStart document contains some outdated commands.
2. `@anthropic-ai/opencode` no longer exists.
3. Use `opencode-ai` instead.
4. LM Studio + Qwen + OpenCode is working successfully.
